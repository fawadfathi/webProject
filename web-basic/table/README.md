# HTML Table Tag

## Description

The HTML `<table>` tag is used to organize and display data in rows and columns. Tables are useful for presenting structured information such as student records, class schedules, prices, and grades.

## Basic Syntax

```html
<table></table>
```

## Common Table Tags

| Tag         | Description                |
| ----------- | -------------------------- |
| `<table>`   | Defines an HTML table.     |
| `<tr>`      | Defines a table row.       |
| `<th>`      | Defines a header cell.     |
| `<td>`      | Defines a data cell.       |
| `<caption>` | Adds a title to the table. |
| `<thead>`   | Groups the header rows.    |
| `<tbody>`   | Groups the main data rows. |
| `<tfoot>`   | Groups the footer rows.    |

## Common Attributes

| Attribute | Description                         |
| --------- | ----------------------------------- |
| `colspan` | Makes a cell span multiple columns. |
| `rowspan` | Makes a cell span multiple rows.    |
