# HTML Typography

## Description

HTML typography refers to the elements used to organize and display text on a webpage. These elements help create headings, paragraphs, emphasized text, and other text structures.

HTML provides different tags to give text meaning and structure, while CSS controls its visual appearance, such as font size, font family, color, and spacing.

## Common Typography Tags

| Tag             | Description                                                                |
| --------------- | -------------------------------------------------------------------------- |
| `<h1>`          | Defines the main heading.                                                  |
| `<h2>` – `<h6>` | Define headings of different levels.                                       |
| `<p>`           | Defines a paragraph.                                                       |
| `<strong>`      | Indicates important text, usually displayed in bold.                       |
| `<b>`           | Draws attention to text without adding importance.                         |
| `<em>`          | Emphasizes text, usually displayed in italics.                             |
| `<i>`           | Represents text in an alternate voice or mood, often displayed in italics. |
| `<mark>`        | Highlights text.                                                           |
| `<small>`       | Represents side comments or small-print text.                              |
| `<del>`         | Represents deleted text, usually displayed with a line through it.         |
| `<ins>`         | Represents inserted text, usually underlined.                              |
| `<sub>`         | Displays subscript text.                                                   |
| `<sup>`         | Displays superscript text.                                                 |
| `<br>`          | Creates a line break.                                                      |
| `<hr>`          | Represents a thematic break, often displayed as a horizontal line.         |

## Common CSS Typography Properties

| Property          | Description                                     |
| ----------------- | ----------------------------------------------- |
| `font-family`     | Specifies the typeface.                         |
| `font-size`       | Sets the size of the text.                      |
| `font-weight`     | Controls the thickness of the text.             |
| `font-style`      | Sets text to normal or italic.                  |
| `color`           | Sets the text color.                            |
| `text-align`      | Aligns text horizontally.                       |
| `text-decoration` | Adds or removes decorations such as underlines. |
| `text-transform`  | Changes letter capitalization.                  |
| `line-height`     | Controls the space between lines of text.       |
| `letter-spacing`  | Controls the space between letters.             |

## Best Practices

- Use heading tags in a logical hierarchy.
- Use `<strong>` and `<em>` when the meaning of the text requires importance or emphasis.
- Use CSS to control the visual appearance of text.
- Choose readable fonts and appropriate font sizes.
- Maintain sufficient contrast between text and its background.
- Use semantic HTML elements instead of relying only on visual styling.
